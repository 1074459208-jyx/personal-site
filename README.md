# 江旭 · AIGC 影像作品集（GitHub Pages 静态版）

## 怎么上传到 GitHub Pages（三步）

1. 打开 github.com，登录后点右上角 **New repository**
   - Repository name 随便起，例如 `portfolio`
   - 选 **Public**（Private 仓库的 Pages 功能要付费）
   - 点 Create repository

2. 进仓库后点 **uploading an existing file**，把本文件夹里的 `index.html` 和 `assets` 文件夹一起拖进去，点 **Commit changes**

3. 进仓库 **Settings → Pages**
   - Source 选 **Deploy from a branch**
   - Branch 选 **main**，目录选 **/ (root)**，点 Save
   - 等 1~2 分钟，页面顶部会出现你的网址，形如
     `https://你的用户名.github.io/portfolio/`

这个网址谁点开都能看，不需要登录。

## 封面图怎么放

把封面图片命名成 `1.jpg`、`2.jpg` … `5.jpg`，放进 `assets/covers/` 文件夹。
编号对应作品顺序：

| 文件名 | 作品 |
|---|---|
| 1.jpg | 容错率 |
| 2.jpg | 石头落水四次 |
| 3.jpg | 20 岁越过了那座山 |
| 4.jpg | 从书信中走出来的清溪 |
| 5.jpg | 狩猎 |

没有图的位置会自动显示作品名称占位，不会出现裂图。

图片建议 3:4 竖版，宽度 1200px 左右，单张控制在 500KB 以内比较快。

## 视频怎么放

本静态版没有上传后台，视频用**外部平台链接**：

- 在页面上点作品卡片里的「加外链」，粘贴 B 站 / YouTube / 小红书 / 视频号的视频地址
- 填好后弹窗里会出现「在外部平台观看」按钮，点击直接跳转
- 链接会自动清洗：去掉空格、自动补 `https://`、从带中文的分享文案里提取网址

## 改文字内容

页面上的介绍、经历、作品描述都可以直接点进去改，改完自动存在你当前浏览器里。

**注意**：这种改动只有你自己这台电脑的浏览器能看到，别人打开看到的还是文件里的原文。
要永久改给所有人看，得改 `index.html` 里的文字再重新上传一次。

## 和线上后台版的区别

| | 这个静态版 | 妙搭后台版 |
|---|---|---|
| 访客免登录 | ✅ 直接打开 | 需要在应用设置里开放可见范围 |
| 网页上传图片/视频 | ❌ 要手动放文件夹 | ✅ 后台点上传（单文件上限 100MB） |
| 改内容 | 改文件重新上传 | 后台直接改 |
| 数据库 | 无 | 有 |
| 费用 | 免费 | 免费（有存储上限） |
